# mirrorai

[![npm version](https://img.shields.io/npm/v/mirrorai.svg)](https://www.npmjs.com/package/mirrorai)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Node](https://img.shields.io/node/v/mirrorai.svg)](https://nodejs.org)

**Codebase-aware AI rules generator.** Produce `CLAUDE.md`, `.cursorrules`, `.windsurfrules`, GitHub Copilot instructions, and Cline rules directly from your existing code — so AI assistants strictly follow your project's real patterns, stop drifting, and consume far fewer tokens.

> Don't let AI invent its own way. Make it mirror what you've already built.

**Language- and stack-agnostic** — works for Vue / React admin panels, Go microservices, Python data pipelines, Rust CLIs, Flutter apps, and anything else with discoverable patterns.

---

## The Problem

You spent months establishing conventions in your project: a wrapped component library, a custom request layer, a standard module structure. Then you brought in an AI assistant — and it ignored all of it.

Every project has different conventions, and every AI session starts from zero. You end up spending more time correcting AI output than you saved generating it.

**mirrorai turns your existing code into rules the AI must follow, and extracts the high-frequency patterns into skeletons you can generate with zero tokens.**

---

## Install

```bash
npx mirrorai install
```

This copies `mirror-init.md` into `.claude/commands/` — a Claude Code slash command. Everything else is generated by the AI after analyzing your project.

> **Not using Claude Code?** Open `.claude/commands/mirror-init.md` and paste its contents as a prompt directly into your AI tool (Cursor, Windsurf, Copilot Chat, Cline, etc.). The analysis and file generation work the same way.

---

## Usage

**1. Initialize (once per project)**

Run `/mirror-init` in your AI tool. You'll be asked:
- Which AI tools to support (Claude Code / Cursor / Windsurf / Copilot / Cline)
- Whether to generate a plopfile and skeleton templates for zero-token code generation

The AI then analyzes your project and produces the appropriate rule files, slash commands, plopfile, and templates. It runs a syntax-and-semantic validation pass at the end; broken generators are either auto-fixed or removed.

**2. Daily development**

The generated `CLAUDE.md` includes an *Auto-Execute Rules* section, so the AI identifies the scenario from your description and applies the right pattern without an explicit command:

```
You:  Add a leave-of-absence approval flow.
AI:   (recognizes the approval pattern)
      → generates the endpoint, tests, and route using project conventions
```

**3. Quick skeleton generation (zero tokens)**

```bash
npx plop --help                       # list available generators
npx mirrorai new <pattern> <name>     # scaffold the skeleton; AI fills in the business logic
```

## How It Works

```
Your project
   ↓
Detect language, framework, and stack from manifest files
   ↓
Scan business code and cluster files by unit type
   ↓
Score and filter: appears ≥ 3 times, ≥ 50 lines per file, ≥ 80% similarity
   ↓
Generate up to four artifact types (based on your selections):
   ├─ Rule files:     CLAUDE.md / .cursorrules / .windsurfrules / ...  (always)
   ├─ Slash commands: .claude/commands/*.md, one per pattern            (Claude Code only)
   ├─ plopfile:       generators that match the commands one-to-one     (opt-in)
   └─ Templates:      .hbs files extracted from your actual code        (opt-in, any language)
```

The entire analysis runs inside your AI tool on your existing subscription — **no API key required**.

## Re-Running

You can run `/mirror-init` again at any time. It detects existing files, annotates which ones are user-authored vs. mirrorai-generated, then offers three actions:

- **Regenerate everything** — re-runs tool selection, so you can add or remove tools
- **Refresh existing files** — regenerates all detected files without adding new tools
- **Select specific files** — enter file numbers (e.g. `1,3,4`) to regenerate only those

Any file that wasn't generated by mirrorai (detected via marker comment) gets a per-file m/o/s prompt before it's touched, so your own content is never silently clobbered.

## Requirements

- Node.js 18+ (for `npx mirrorai` and plop)
- A subscription to any of: Claude Code, Cursor, Windsurf, Copilot, Cline
- The analyzed project itself has **no language or framework requirements**
